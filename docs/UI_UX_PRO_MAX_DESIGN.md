# Supply Chain Atlas：UI/UX Pro Max 设计系统与验收

> 2026-11-19 · 页面级设计规范 · 适用于眼镜、汉高胶黏剂、电脑键盘及新产品。
>
> 依据 [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的 accessibility → interaction → responsive → typography/color → charts 优先级，结合本仓库的 evidence-first 产品约束制定。本文不把结构完备度误认为事实正确率。

## 1. 产品目标与主要任务

使用者是供应链研究人员，主要任务依次为：

1. 从产品目录进入技术图谱。
2. 通过材料名、工艺、部件查找节点（支持 `/` 快捷键、12 条结果预览及完整数量）。
3. 选择节点并观察从成品到该节点的高亮路径。
4. 用“状态聚焦”定位待深研、待复核或已审核节点。聚焦仅**淡化**其他状态，不过滤祖先节点或改变数据范围。
5. 在右侧六标签研究面板核对身份、技术、企业与市场口径、关系证据和后续调查任务。
6. 用原始来源与 claim/source ID 追溯论断；未知值维持未知。

## 2. 视觉与交互规范

- **风格**：高信息密度的专业研究工作台；低干扰深蓝底色，青蓝色交互强调。避免夸张动效、彩色渐变和虚假的“高完成率”。
- **基本字号**：正文 16px；图表与紧凑元信息允许 12–14px；正文行高至少 1.5。
- **语义颜色**：`--sc-success` 仅用于语义审核完成，`--sc-warning` 用于档案待复核，`--sc-info` 用于有来源待研究，灰蓝用于结构信息；始终配合文字状态，不仅靠颜色。
- **容器**：桌面图谱主画布 + 右侧独立滚动研究面板（宽 420–600px）。窄屏上下布局，图谱先于详情。
- **触达**：核心按钮/搜索/下拉/标签至少 44px 高（少量纯文本链接视排版而定）；保留焦点轮廓和不遮挡的焦点状态。
- **运动**：仅使用克制的 hover/交互反馈，遵从 `prefers-reduced-motion`。
- **响应式**：1080px 改上下布局；700px 使搜索、状态筛选及主要操作可换行，防止固定宽度造成横向溢出。
- **状态筛选**：五类阶段名必须与数据层原字段 `reviewed/dossier_pending/source_note/annotated/structural_only` 一致。没有证据不等于“已审核”。
- **空状态**：查询无结果明确告知；没有市场数据时不显示“0%”，没有供应证据时不猜采购关系。

## 3. 信息架构

| 视图 | 一屏内必须看到 | 后续操作 |
|---|---|---|
| 产品目录 | 产品、类别、节点及研究摘要 | 进入该产品图谱 |
| 图谱工具栏 | 路径/搜索/状态聚焦/缩放/展开折叠 | 直接定位具体节点 |
| 图谱画布 | 技术路径、选中节点、研究状态图例 | 单击查看、双击折叠、键盘上下/左右导航 |
| 研究详情 | 节点身份、来源状态、风险提示、六个标签 | 读取证据、企业信息、任务 |
| 企业详情 | 关联材料、产品、合作证据与指标口径 | 返回先前节点 |

每个节点面板都从“总览”标签开始。不能把 `associated_with` 图谱边显示为已确认的采购关系。市场份额只有满足地区、年度、指标、统计分母与来源才可做可比呈现。

## 4. 代码与构建位置

- `web/assets/ux_pro_max.css`：设计令牌、响应式尺寸、对比度、焦点与状态视觉。覆盖既有页面样式，不改数据。
- `web/assets/app.js`：图谱搜索结果、状态聚焦、路径高亮、节点键盘导航。
- `web/assets/node_panel.js`：六个 tab 和 tabpanel 的 ARIA 关系，左右键/Home/End 导航，防止重渲染产生重复点击委托。
- `scripts/build_site.py`：为新增 CSS 注入部署版本号并计入 build_id 哈希；所有资源仍由 GitHub Pages 静态托管。
- `tests/test_ux_pro_max.mjs`：无障碍结构、事件处理器、基础功能契约回归。

## 5. 验收清单

```bash
node --check web/assets/app.js
node --check web/assets/node_panel.js
node --test tests/test_node_panel.mjs tests/test_research_status_ui.mjs tests/test_keyboard_atlas.mjs tests/test_ux_pro_max.mjs
python3 -m unittest discover -s tests -v
python3 scripts/research_cli.py validate-skills
python3 scripts/build_site.py
python3 scripts/verify_pages_release.py --dist dist
```

浏览器人工验收（需真实设备，不可用静态测试冒充）：

- Desktop 1440×900、Tablet 820×1180、Mobile 390×844：工具栏不溢出，左右/上下分栏切换正常，右侧标签可独立滚动。
- 输入中文材料名，看到匹配数量、前 12 条结果及路径；点击一条高亮其祖先链，折叠分支自动展开。
- 选择“结构信息 · 待深研”时其他节点仅淡化，所有技术连线仍可追踪。
- 从节点进入企业后点击“返回节点”，不触发重复渲染或重复操作。
- 仅键盘完成搜索、方向键切换节点、方向键/Home/End 切换详情标签；Tab 焦点清晰可见。
- 使用 200% 页面缩放、深色高对比和系统减少动态效果检查可读性。
- 眼镜/汉高/键盘三产品回归，验证无证据节点仍显示待深研、未知份额不被转成 0%。
