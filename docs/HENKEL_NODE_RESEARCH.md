# 汉高胶黏剂与密封材料产业链（研究草稿，2026-11-18）

## 研究对象和关键边界
本系列研究的是 **Henkel Adhesive Technologies 多品牌组合**，不是一个产品SKU、一个标准配方或某一间工厂的真实BOM。牌号、品牌、功能层、工业用途与物料上游属于不同类型关系，不能统一看成“配料”。

- 工业品牌：LOCTITE / TECHNOMELT / AQUENCE / TEROSON / BONDERITE。BONDERITE以表面预处理/处理工艺为主，非“胶水”同义词。
- 聚合物体系：瞬干氰基丙烯酸酯、厌氧双甲基丙烯酸酯、双组分环氧、EVA/聚烯烃热熔、反应型PUR、AQUENCE水性胶、SMP弹性密封。
- 上游链：EVA→乙烯+醋酸乙烯酯；环氧树脂→典型BPA/环氧氯丙烷路线；PUR→聚醇/异氰酸酯族；SMP按无异氰酸酯技术与PUR分开研究。
- 终端行业：汽车、电子、包装、木工、家电、建筑和轨交等。不能推断SpaceX或任何指定OEM采购。
- 设备：混配、分散、过滤、点胶、热熔泵、流变/剪切试验。未公开设备采购合同。

## 深度调查尚未完成

- **汉高上游化工供应商TOP3及实际采购**：公开材料尚不能确证企业合约；不得把环氧/PUR产业大厂当作汉高供应商。
- **各化学体系全球/中国同口径TOP3**：本次不编造，没有独立定量排名。
- **细分牌号SDS与价格**：该版本未抓取每个地区/批次，TDS不能替代监管成分披露。
- **客户/应用实证**：官网行业介绍不是指定厂商合作合同。
- **双重用途**：汉高化学品在航天/汽车等行业存在应用，但不能等同于对应型号的认证采购。
- **数据独立性**：本批多为汉高官方资料；事实可以支持厂商自述产品技术，但不足以形成独立的市场竞争结构验证。
