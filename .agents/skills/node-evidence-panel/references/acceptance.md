# 节点面板验收清单

- [ ] 产品/分类/化学体系三种节点均能显示清楚，BONDERITE等表面处理不误标为普通胶水。
- [ ] 六大标签可切换，数据来源及草稿标识持续可见；不堆砌JSON。
- [ ] 每条物性数据关联source_id，显示单位与测试条件/版本；关键数据不互相换算成虚假TOP3。
- [ ] 0、null、unknown区分清楚；百分比只在真正的市场份额指标中出现。
- [ ] 上下游导航可点击，分类边不等于购销或化工投料，跨产品反查不自动推断实际供应商。
- [ ] XSS escaping、https链接校验、键盘可用、移动端布局、长文字换行。
- [ ] 技能镜像 .codex/.pi/.claude 与规范源完全一致。
- [ ] 静态单测、CI、Pages部署逐项记录；浏览器手工回归需单独证明。
