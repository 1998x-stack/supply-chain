# 图谱规范
身份键优先：材料(CAS + grade + property + process scope)；公司(注册主体/LEI/工商登记+国家)；设备(型号/制造商/版本)；产品(型号/配置/批次)。
关系方向 upstream_id→downstream_id，审查转换工艺和组件边是否被错误方向化。
图谱有五种路径：物料路径、企业商品能力、已证实商业关系、控制权关系、风险传导，不能混用。
Graph UI应展示证据层、采样时间、来源、未知状态；对超大图做懒加载、邻居展开、路径数与深度上限。
数据库 product_view_node 支持同一实体多视图；引用的材料ID必须跨产品稳定。
