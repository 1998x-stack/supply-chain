# 键盘关键材料追溯与易错点

| 材料/系统 | 合法的工业路径 | 禁止推断 |
|---|---|---|
| PBT键帽 | 对苯二甲酸(PTA)/BDO→聚酯树脂→改性配混→注塑、染色或双色注塑 | PBTfans=100%纯PBT，或KBDfans就是树脂聚合厂家 |
| ABS键帽 | 苯乙烯、丙烯腈和丁二烯→ABS共聚/改性→注塑 | 某ABS品牌就是指定键盘的真实材料供货商 |
| MX触点 | 典型金属合金/镀金/金属弹片 | 每款机械轴都有CHERRY Gold Crosspoint |
| 霍尔磁轴 | 永磁体+位置传感器IC+MCU/ADC方案 | Gateron KS20的磁钢一定是NdFeB或SmCo |
| FR-4 PCB | E-glass布+环氧预浸料+电解铜箔→压合/钻孔/电镀 | Isola FR408HR数据可替代全部PCB材料 |
| BLE无线 | SoC/射频匹配/天线 + 电池+HOGP | Nordic nRF52840必然被某品牌装机 |
| PET薄膜电路 | PET膜 + 导电浆料/碳墨 + 隔离层 | 薄膜键盘与机械轴共享同一金属接点BOM |
| 铝合金外壳 | 铝土矿→氧化铝→电解铝→铝合金→CNC/阳极氧化 | 某个铝土矿生产国家=某品牌外壳采购国 |
| 锂电系统 | 电芯正负极/隔膜/电解质+保护与充电IC | 所有无线键盘都是锂电、或所有键盘都需电池 |
| 芯片 | 电子级硅→晶圆制造→封测→MCU/Hall IC/LED驱动 | 某一IC厂的生产能力证明真实OEM供货 |

生产能力、质量等级、测试环境、实际SKU、制造厂和品牌所有者必须分列。稀土国家产量与芯片市场份额不可直接换算。
