# 键盘专属验收清单

- [ ] keyboard产品注册于消费电子，网页可展开、折叠、缩放和节点导航。
- [ ] 机械接点、霍尔磁轴、薄膜/剪刀脚独立；有线键盘不强制电芯和无线SoC。
- [ ] 节点ID、父子拓扑、跨分支关系、来源ID及SQLite外键全部通过校验。
- [ ] 数值包含具体型号/牌号、单位、工况、版本与来源。
- [ ] 各dossier有匹配ledger，所有草稿只显示待审阅。
- [ ] 未验证的供应商、市场TOP3、采购份额继续为空。
- [ ] 页面同时注册eyewear、henkel-adhesives和keyboard；构建和发布前校验压缩数据。
- [ ] 验证Python测试、Node测试及Skill镜像后方可合并。
- [ ] 浏览器完整人工回归独立验收，不把CI成功当成完成浏览器测试。
