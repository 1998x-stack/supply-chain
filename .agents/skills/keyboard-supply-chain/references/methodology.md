# 键盘供应链研究方法

严格区分机械/霍尔/薄膜三种触发技术以及USB/BLE/私有2.4GHz通信、USB供电/可充电电池/一次电池等互斥构型。图谱是研究导航，不能合并所有可选零部件成为一份BOM。

阅读顺序：
- ontology.md：构型/异或选项/边类型/全局实体设计。
- materials.md：工程塑料、金属、磁材、PCB及半导体上游深度路线。
- evidence.md：原始厂商/标准及独立来源/反证规则。
- docs/KEYBOARD_SUPPLY_CHAIN.md：本轮产业链研究文档。
- docs/KEYBOARD_DEEP_SEARCH_PLAN.md：下一批研究任务。

所有企业采购记录须有买方、卖方、料号/品级、时间范围及直接证据。证据来源不完整时保持UNKNOWN，研究机器校验不能代替人工语义审查。
